# 本地 WebUI 工作台 · 设计决策记录

> 状态：设计确认中（2026-11-11）。本文记录 PM/架构决策，随讨论更新；实现排在 MCP 主集成（0.2.0）之后。

## 定位

DFSC 内的 agent 对话覆盖“帮我用 X 音色念这段”的轻场景；**本地 WebUI 工作台**覆盖重场景：浏览 39 个音色并试听对比、调参合成、导出、复刻音色，未来接入 Music 生成。两者共用同一套核心（config/client），两个入口：`src/index.js`（stdio，给 agent）与 `webui/server.mjs`（HTTP，给人）。

选择本地 WebUI 而非求上游做前端加载器的理由：上游明文拒绝第三方 HTML/JS 入口（架构决策，非遗漏）；本地服务不请求宿主持任何能力，市场规则零冲突；UI 完全自主迭代。

## 架构决策

| 决策 | 结论 | 理由 |
| --- | --- | --- |
| 运行形态 | **独立进程，手动启动**（`node webui/server.mjs` / `npm run webui`） | 绝不塞进 MCP 进程：DFSC 拉起的是 stdio 服务，暗起 HTTP 监听是平台最忌讳的静默额外行为 |
| 代码复用 | 复用 `src/config.js` + `src/client.js` + 工具逻辑；DFSC 托管用户的 Key 经 vendor 读取器直接可用 | 一套后端两个前端，不维护两套配置/密钥/API 逻辑 |
| 密钥边界 | 只在服务端（Node 进程），浏览器零暴露；页面纯静态，API 全走本地代理 | 静态 JS 拿 Key 等于把 Key 写进 localStorage |
| 网络边界 | 绑 `127.0.0.1`；启动 token 鉴权 | localhost ≠ 只有你能访问；防同机其他用户滥用额度 |
| 端口 | **固定默认端口 + 全链路覆盖**（见下节） | 书签/收藏夹/自启依赖固定地址（对标 AstrBot） |
| 配置来源 | CLI flag > 环境变量 > 私有 env 文件 > 默认值 | 复用既有配置链；端口等 WebUI 参数不进 DFSC 宿主设置（宿主不感知 WebUI） |
| 设置页 | WebUI 内置设置屏：独立用户可直接保存 Key/模式/地址（写私有配置）；DFSC 托管用户只读展示来源 | 顺势吞掉 configure.mjs 的活，给人用的配置界面 |
| 打包 | 随插件包分发（静态文件几十 KB），文档标注“可选、手动启动、本地服务” | 市场审核说清楚；自带服务要在插件描述与 UPSTREAM.md 声明 |

## 启动与端口

- 默认端口取不常见值（建议 **8791**，避开 AstrBot 6185 等常见占用）。
- 覆盖优先级：`--port <n>` > `STEPAUDIO_WEBUI_PORT`（环境变量/私有 env 文件）> 默认 8791。
- `--port 0` = 临时随机端口（一次性使用，不持久化）。
- **端口冲突**：固定端口被占用时启动失败，错误信息指明端口与占用进程建议（“端口被占用，换 `--port` 或结束占用进程”），不静默跳随机端口——固定端口的意义就在于地址可预期。
- 启动时打印完整地址 `http://127.0.0.1:<port>/?token=<token>`（可直接复制）；默认尝试自动打开浏览器（`--no-open` 关闭，无显示环境时自动跳过）。
- 鉴权与固定端口的关系：token 为**稳定值**（存私有配置，非一次性），浏览器首次访问输入后存 sessionStorage；固定端口 + 书签场景下每开一个浏览器会话输一次。`--no-token` 可显式关闭（文档注明仅限可信单用户机器）。后续如需多用户/常驻再上加密码登录（AstrBot 模式）。

## v1 范围（严格砍住）

1. **音色库**：39 官方 + 已复刻，场景筛选，点击选中，试听按钮（固定样本句，服务端合成，原地播放）。
2. **合成台**：文本 + 音色/instruction/语速/音量/格式 → 合成 → 播放 → 下载。
3. **设置**：模式/地址/模型/Key/输出目录（独立用户可保存，托管用户只读）。

**不进 v1**：复刻工作流（上传→转写→命名→试听）、Music 页、批量合成、历史记录。各排 0.3.0+。

## 验收

- playwright 实际打开页面：选音色→试听→合成→导出全流程截图验证（stdio 测试套不适用 WebUI）。
- 端口冲突、token 拒绝、`--no-open` 无显示环境均有对应用例。
- 安全用例：页面源码与网络响应中不出现 Key；非 127.0.0.1 来源拒绝。
